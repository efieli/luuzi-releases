LUUZI 0.1.0.220

Segurança reforçada: os botões do mouse só abrem aplicativos de verdade. Se um arquivo de ajustes importado apontar para um script ou programa que não é um app, o LUUZI bloqueia e avisa.

Importar ajustes ficou mais seguro: o LUUZI só aceita arquivos de ajustes comuns, de até 5 MB.

Os registros de erros do LUUZI (pasta Logs/LUUZI) agora ficam visíveis só para você.

O LUUZI deixa explícito que não aceita conexões sem HTTPS.
